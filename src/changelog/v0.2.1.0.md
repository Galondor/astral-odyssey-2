# v0.2.1.0

## Interface

- Inventory tabs scroll horizontally when space is limited.
- The sidebar now displays the current game version.
- Added a changelog reader with a tab for each published changelog.
- Removed being able to send messages while in town.
- The top navbar shows current health, stamina, and power beside the player name on larger screens.

## Features

- Added a Leaderboards sidebar screen with tabs for highest level, highest gear score, and most astra.
- Leaderboard scores are published every 30 minutes on sign-in or save.
- Character names are now unique (exact, case-sensitive matches). Choosing a name saves immediately, including during character creation.
- Existing names are reserved on sign-in. If an older duplicate name is already owned, the player can choose a replacement without an elixir.
- Consumables can be bought and sold on the marketplace, one per listing, with Gear/Consumables filters. Purchases arrive as claimable inbox attachments.
- Admin messages can include the Elixir of Name Changing under Consumable attachments.

## Gameplay

- Added Power Potions & Greater Power Potions that can be purchased from the Apothecary.
- Dungeon bosses have a 5% chance to drop an Elixir of Name Changing. It is not sold by the Apothecary or dropped by other enemies.
- Use the elixir in the inventory to choose a new name immediately. Cancelled, invalid, taken, or failed name changes do not consume it; successful changes save the name and item cost together.
