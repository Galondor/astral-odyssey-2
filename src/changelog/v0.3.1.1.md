# v0.3.1.1

## Balance
- Enemy speed is tripled across the board.
- High-level region bosses have slightly reduced stats.
- Solo dungeon bosses are tougher.
- Group dungeons are now significantly stronger, and attempting solo runs is much more challenging.

## Mobile User Interface & Experience
- The mobile menu now shows a notification dot when any navigation tab has notifications.
- Added bottom navigation on mobile for Gameplay, Character, Town, and Menu.
- Character now has separate Inventory, Equipment, and Stats sections on mobile.
- Made mobile actions and item details easier to tap, and added a collapsible combat log.
