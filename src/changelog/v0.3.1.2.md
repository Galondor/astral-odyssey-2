# v0.3.1.2

## Features
- Leaderboard scores now publish on saves up to every 15 seconds instead of every 30 minutes, and open leaderboards refresh every 15 seconds.

## Mobile User Interface & Experience
- Mobile action buttons now sit just above the bottom navigation.
- Item and consumable tooltips no longer appear on mobile.
- Group dungeons now use a compact mobile combat layout with collapsible party details and combat history.

## Fixes
- Fixed leaderboard publication being rejected when the Giant Slayer title is equipped.
