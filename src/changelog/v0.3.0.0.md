# v0.3.0.0

## Interface

- The top bar now has a placeholder character portrait opening a profile popup with character stats, region, currency, reputation, Main menu, and Log out. Save-state text and inline player details have been removed.
- Mobile navigation stays vertical behind a burger toggle instead of becoming a horizontal strip.
- The mobile menu overlays the current screen and blocks background interactions until dismissed; keyboard focus stays inside the menu.
- Signing in now opens a main menu where you can select a character, resume character creation, or create a new adventurer.
- Return to character selection with the Main menu button outside combat; progress is saved before switching.
- Database account keys are no longer displayed in the interface.
- Characters can be permanently deleted from the main menu after typing their exact name in a warning dialog. Deleting a character frees their slot and removes their progress, mail, and marketplace listings.

## Features

- Accounts have three character slots by default. Each character has its own numeric ID and separate progress, name, inbox, marketplace listings, and leaderboard entry.
- Existing characters are imported automatically without losing progress or pending mail and sales. The original cloud save is retained as a backup.
- Admin messages and broadcasts can attach custom gear with a chosen name, slot, rarity, condition, level, astra value, main stat, substats, ability, handedness, and optional holofoil colors. Choose Custom gear in the attachment picker and select T0-T7 for each stat; blank substats are omitted. Each copy rolls within the exact selected tiers when attached. Main stats use the shared 0-22 scale, while substats use item level and two-handed scaling; tiers with no possible roll are disabled. Items retain their rolled values when claimed, without rerolling or recipient-level scaling.
- Admin messages and broadcasts can send titles as claimable mail attachments. The Unique title "Monarch of the Odyssey" recognizes players who reached level 100 before version 0.3.0.0; it is not awarded automatically.

## Gameplay

- New characters receive seven Average Common gear pieces matched to their highest core stats; the Character tab shows a dot while gear, consumables, or gemstones are unread.
- Custom gear supports random holofoil colors: enable Force holofoil and leave both color fields blank. Colors are generated when attached and preserved when claimed; entering colors still requires two valid #RRGGBB hex codes.
- Revamped stats on items.
- Item tooltips separate the main stat from the first substat with a divider.
- Hovering over gear shows its stats without a comparison. Selecting gear in your inventory, equipment, or the Gear Trader opens a details popup with optional comparisons and available actions. Favorites are managed in the popup instead of by right-clicking.
